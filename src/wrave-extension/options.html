General & Connection

Configure ports and local endpoints for connected AI assistants.

Port for the local HTTP/WebSocket Model Context Protocol server.

CDP port when Brave is launched with --remote-debugging-port.

Optional secret token required for HTTP requests.

Security & Permissions

Control what operations connected assistants are allowed to execute.

Prevent automated typing into password and payment fields.

Allow connected clients to evaluate JavaScript in the tab context.

Permit reading cookies for authenticated session inspection.

Client Setup

Add Wrave MCP server to your AI assistants and coding tools.

Antigravity (Stdio Mode - Recommended)

In ~/.gemini/config/mcp_config.json (runs automatically on startup):

{
  "mcpServers": {
    "wrave": {
      "command": "node",
      "args": ["C:\\Users\\walid\\Desktop\\weed\\wrave\\src\\wrave-engine\\cli.js", "--stdio"]
    }
  }
}

Antigravity / Cursor / Windsurf (SSE Mode)

Requires daemon running via node cli.js --server --port 8282:

{
  "mcpServers": {
    "wrave": {
      "serverUrl": "http://127.0.0.1:8282/mcp/sse"
    }
  }
}

Claude Code CLI

Run once in your terminal:

claude mcp add wrave -- node "C:\Users\walid\Desktop\weed\wrave\src\wrave-engine\cli.js" --stdio
